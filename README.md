A program that writes one one-line comedy joke (148 characters) for make.fun's "One-Liner Marathon" bounty, $2 in USDC. The joke: a bank flags a $4 coffee as suspicious but waves a $2,000 crypto "opportunity" straight through — turns out fraud has better branding than the account holder.

## Run it

```sh
node main.ts
```

It writes the joke deterministically to `/output/entry.txt` — no network, no randomness, no runtime state. The same bytes come out on every run.
